# 靠近解锁 - 比亚迪蓝牙接近自动解锁系统

## 🚗 项目简介

这是一个基于**华为HarmonyOS平台**的比亚迪蓝牙接近自动解锁系统。通过蓝牙近场通信（BLE）和GPS定位技术，实现：

- ✅ **蓝牙接近检测** - RSSI信号强度实时计算距离
- ✅ **自动解锁/锁车** - 基于比亚迪官方蓝牙车控协议
- ✅ **地理围栏** - 记忆停车位置，离开围栏后自动启动后台扫描
- ✅ **持续监控** - 进入围栏内持续移动时启动活跃解锁监控
- ✅ **多功能控制** - 支持闪灯、鸣笛等车辆控制功能

## 🎯 核心特性

### 1. 蓝牙接近检测
- 通过RSSI信号强度检测设备距离
- 默认3米范围内自动解锁
- 支持RSSI和距离双重阈值验证

### 2. 围栏管理
- 每次锁车自动记录停车位置
- 默认100米围栏半径（可自定义50-500米）
- 围栏外启动后台扫描（30秒检测一次）
- 围栏内移动后启动活跃监控

### 3. 后台扫描
```
锁车 → 记录停车位置 → 启动后台扫描
        ↓
    离开围栏？→ 是：持续后台扫描
        ↓ 否
    进入围栏且移动？→ 是：启动活跃监控
```

### 4. 比亚迪官方协议
- 遵循比亚迪BLE车控规范
- 支持开锁、锁车、闪灯、鸣笛等功能
- 包含校验码和消息验证机制

## ⚙️ 参数调整

### 距离阈值
- **推荐值**: 3-5米
- **范围**: 1-10米
- **影响**: 决定触发自动解锁的最大距离

### RSSI阈值
- **推荐值**: -60dBm
- **范围**: -30 ~ -100dBm
- **说明**: 值越大（如-50）越敏感

### 围栏半径
- **推荐值**: 100米
- **范围**: 50-500米
- **说明**: 停车位置周围的有效范围

### 后台扫描间隔
- **推荐值**: 30秒
- **范围**: 10-60秒
- **说明**: 在围栏外的检测频率

## 📊 工作流程

### 正常使用流程

```
应用启动
  ↓
连接蓝牙设备
  ↓
点击"锁车" → 记录停车位置[lat, lon]
  ↓
启动后台扫描 → GPS检测当前位置
  ↓
离开围栏？
  是 ├→ 继续后台扫描（30秒检测一次）
  否 └→ 进入围栏
      ↓
    有移动？ 
    是 ├→ 启动活跃监控（每500ms检查RSSI）
    否 └→ 继续后台扫描

接近到设定距离 → 自动发送开锁指令
  ↓
车辆解锁 → 停止监控
```

## 🔐 安全特性

✅ **白名单管理** - 只有授权设备能触发解锁
✅ **连接验证** - 设备必须已连接才能解锁
✅ **RSSI验证** - 验证信号强度在合理范围内
✅ **距离验证** - 双重距离校验防止误触发
✅ **冷却保护** - 同一设备5秒内只能解锁一次
✅ **加密协议** - 遵循比亚迪官方通信规范
